Key Features

Automate your vessel edge infrastructure with production-ready Ansible roles

Automated Cluster Setup

Rapidly configure and deploy multiple edge devices across your fleet with consistent, repeatable infrastructure.

Secure Data Transmission

Tailscale mesh VPN ensures encrypted data flow from vessels to onshore systems with zero-config networking.

Network Security

Comprehensive firewalling, SSH hardening, and network segmentation for defense-in-depth security.

Marine Data Integration

Signal K server for NMEA 2000/0183 sensor data ingestion with ELK stack for local visualization.

Centralized Logging

Rsyslog and Loki/Promtail for efficient log collection, aggregation, and forwarding to SOC.

Infrastructure as Code

Version-controlled, auditable configuration with Ansible roles for complete fleet management.

Ansible Roles

Production-ready roles for maritime edge infrastructure

marine_haris

Complete maritime edge stack: Signal K, ELK, CAN bus, and data aggregation services.

elk_stack

Elasticsearch, Logstash, and Kibana for log storage, processing, and visualization.

tailscale

Mesh VPN setup for zero-config encrypted vessel-to-shore communication.

loki_promtail

Grafana Loki and Promtail for lightweight log aggregation and shipping.

sshd

Hardened OpenSSH daemon configuration for secure remote access.

firewalld

Host-based firewall management for network segmentation and security.

rsyslog

Log collection and forwarding to centralized logging infrastructure.

users_groups

User and group management across fleet devices.

Getting Started

Deploy your first vessel edge device in minutes

Clone the Repository

# Clone the repository git clone https://github.com/anomalyco/watchtower.git cd watchtower

Configure Your Inventory

# hosts [vessels] haris_sinilind ansible_host=10.0.0.10 [msoc_core] haris_gateway ansible_host=193.40.157.80 haris_citadel ansible_host=10.0.0.5

Run the Playbook

# Deploy to vessel edge devices ansible-playbook -i hosts playbooks/group_vessel_edge/main.yml # Deploy to MSOC core infrastructure ansible-playbook -i hosts playbooks/group_msoc_core/main.yml
